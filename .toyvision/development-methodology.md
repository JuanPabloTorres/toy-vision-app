# Development Methodology

1. Identify the authoritative owner and trace the full current flow.
2. State objective, files, risks, tests, and acceptance before editing.
3. Make the smallest coherent change without adding parallel product truth.
4. Protect temporal evidence, monotonic rewards, human confirmation, privacy,
   and camera-loop performance.
5. Add focused domain/controller/UI tests for changed behavior.
6. Run `flutter analyze`, the full current test suite, and an APK build.
7. For release-facing camera work, install the exact hashed APK and certify the
   real-device flow with supported toys.

Historical phase documents are research, not implementation requirements.
