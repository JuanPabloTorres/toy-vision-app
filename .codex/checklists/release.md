# Release

- [ ] Source/diff and artifact/APK/model hashes match the evidence.
- [ ] Architecture, static, unit/component, integration and replay gates pass.
- [ ] Full adversarial matrix has no critical failure or hidden row.
- [ ] Complete representative corpus meets acceptance criteria.
- [ ] Supported physical Galaxy run passes every required scenario.
- [ ] Gameplay, accessibility, animation/audio/fallback are verified.
- [ ] Privacy defaults and retained certification data are reviewed.
- [ ] Commercial licenses, production app ID and release signing are resolved.
- [ ] Known risks are accepted by the proper owner.
- [ ] Independent release auditor issues PASS.
