# `test-gameplay` recipe

Native skill for changes: `$toyvision-flutter-gameplay-ui`.

Run presentation and feedback tests, then manually/automatically walk
Home→Preparing→Scanning→Ready→Cleaning→Celebration→Home. Check permission/model
failure and retry, one clear action, domain-event feedback, debug separation,
small screen/text scale, reduced motion, and no dead ends. Report physical
camera/animation/audio rows separately.
