# `profile` recipe

Native invocation: `$toyvision-performance-profiling`.

Record exact build/model/delegate/resolution/scenario/environment. Measure
native inference, Dart stages, wall p50/p95, drops, RSS, render timing, thermal,
and battery. Desktop performance tests are regression evidence only. Release
claims require the supported physical-device workflow in
`tools/certify_galaxy_s25.ps1`.
