# `audit` recipe

Native invocation: `$toyvision-architecture-audit`.

Inspect git status, entry points, imports, state/event owners, affected
consumers/tests, legacy docs, Android/assets/tools, and release evidence.
Classify `KEEP / IMPROVE / MERGE / DELETE / CREATE`; separate observed facts
from recommendations. Output current architecture, findings/risk, evidence, and
validation steps. Do not edit unless the user requested implementation.
